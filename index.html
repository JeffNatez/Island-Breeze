CONFIGURATION

Supabase setup

Steps for connecting the website to your database.

Connection details

The current file is configured with the Supabase project URL and publishable key previously supplied. The publishable key is intended for client-side use; database permissions must still be secured with Row Level Security (RLS).

Expected tables: room_types, rooms, guests, reservations, payments, and maintenance.

If these tables do not exist, run the included supabase_setup.sql in the Supabase SQL Editor. If you already have tables with different names or columns, adjust the SQL/app mapping to match your existing schema instead of creating duplicates.

Test: open this file while connected to the internet, then check the green connection indicator. If an error appears, check the browser console and Supabase Table Editor / RLS policies.

Security: this demo uses public browser access policies for a classroom prototype. Do not use real guest personal information or expose it publicly. For production, add authentication and restrict policies to authorized staff.
